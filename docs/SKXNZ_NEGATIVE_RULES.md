# SKXNZ Negative Rules

## Do not create anything that feels
1. Cheap.
2. Cartoonish.
3. Casual.
4. Copied.
5. Cluttered.
6. Fake.
7. Generic.
8. Low-resolution.
9. Over-neon.
10. Legally risky.

## Do not copy
Do not copy the visual identity, assets, names, logos, or copyrighted material of existing brands or marketplaces.

## Do not claim
1. Live payments if payments are not connected.
2. Live delivery tracking if delivery API is not connected.
3. Live AI try-on if not implemented.
4. Verified sellers if verification workflow is not live.
5. Guaranteed authenticity if QC/verification is not active.
6. Real refunds if refund processing is not connected.
7. Public community posting if moderation is not ready.
8. Live mobile apps if they are not built.

## UI mistakes to avoid
1. Hero carousel detached from header.
2. Light/pink navbar patches.
3. Hero images stretched or stacked.
4. Text covering the hero visual.
5. Product cards stretching vertically because of adjacent panels.
6. Product image overlay text blocks.
7. Static mockup replacing a working component.
8. Broken mobile layout.
9. Text overflow outside cards.
10. Duplicate AI widgets.
