# SKXNZ Feature Priorities

## Priority logic
Build the marketplace in the order that makes SKXNZ usable first, premium second, and intelligent third.

## P0 - Must remain stable
1. Homepage visual foundation
2. Navbar/header
3. Product grid/card structure
4. Product images/fallbacks
5. Cart mock flow
6. Demo role system
7. Seller/admin placeholder routes
8. MVP safety labels

## P1 - Next private testing priorities
1. Finish homepage visual QA.
2. Continue product detail consistency.
3. Verify cart image/size flow.
4. Clean category and brand pages.
5. Verify search suggestions and results.
6. Keep AI assistant as SKXNZ-only shopping helper.
7. Do not make unfinished flows look live.

## P2 - Differentiation layer
1. Signal Community planning.
2. Style boards.
3. Tagged products.
4. Admin moderation queue.
5. AI outfit builder improvements.
6. Seller validation flow.

## P3 - Later production systems
1. Real authentication.
2. Production database.
3. Payment gateway.
4. Delivery API.
5. Refund processing.
6. Seller payouts.
7. Real AI provider integration.
8. Mobile apps.

## Features that must stay labeled as placeholder until live
1. Checkout and payments.
2. Delivery tracking.
3. Refund processing.
4. Seller payouts.
5. AI try-on.
6. Real personalization.
7. Seller verification.
8. Public community posting.
