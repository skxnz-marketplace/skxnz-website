# SKXNZ UI Rules

## Core direction
SKXNZ should feel like a premium futurewear marketplace: clean, fashion-led, futuristic, responsive, image-first, and product-first.

## Current approved direction to preserve
The current homepage direction uses:

- Near-white luxury page background
- Dark maroon glass navbar
- Full-width hero connected to the header
- Compact brand pills
- Compact category tiles
- Compact product cards
- Working floating AI assistant

Do not restart this direction without explicit approval.

## Header rules
1. Header must remain dark maroon glass.
2. Header must not have a light pink patch on one side.
3. Search must stay readable.
4. Icons must stay tappable.
5. Header should feel connected to the hero.

## Hero rules
1. Full-width.
2. Connected directly below header.
3. One active slide visible at a time.
4. No stacked broken image layers.
5. Text must not hide the main visual.
6. Images must not stretch.
7. No AfterLast assets or unrelated portraits.

## Product card rules
1. Product images first.
2. Product name, brand, price below image.
3. No large text overlay on product images.
4. Product cards stay compact and equal-height.
5. Product names clamp cleanly.

## AI widget rules
1. Keep one real working assistant only.
2. Do not add static AI chat screenshots.
3. Do not weaken SKXNZ-only guardrails.
4. Do not claim real AI personalization beyond implemented behavior.
