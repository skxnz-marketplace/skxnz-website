# src/data — FALLBACK / DEVELOPMENT DATA

**This is not the production catalogue.** The live catalogue is Supabase
(see `docs/engineering/SOURCE_OF_TRUTH.md`).

Most files here are generated by `scripts/import-sheet-data.py` from the June 2026 planning sheet
`project-data/source-sheets/SKXNZ_MASTER_STORE_DATABASE_FINAL.xlsx`. The rest (`demo-*.ts`,
`skxnz-products.ts`) wrap those files for demo surfaces.

Still read at runtime by: site search, the discovery menu, `lib/data/brands.ts`, and the AI
assistant/stylist (`src/lib/skxnzAssistant.ts`, `src/lib/ai/*`). Anything added there should read
Supabase instead.

Known issue: the sheet's image paths for several products are wrong, and `products.ts` carries
manual fixes. **Re-running the import script overwrites those fixes.** Correct the sheet first.
