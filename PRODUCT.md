# Product

## Register

product

## Users

SKXNZ buyers, sellers, and operators using an authenticated multi-seller fashion marketplace. On checkout, buyers need to review real cart and address information, create a safe unpaid draft, understand failures, and continue without duplicate orders or implied payment.

## Product Purpose

SKXNZ helps people discover and manage premium futurewear marketplace activity. The current checkout purpose is controlled readiness: validate real catalog and address data, create one server-authoritative unpaid draft, and clearly separate that draft from future payment and fulfilment.

## Brand Personality

Premium, precise, future-facing. The voice is direct and calm, with no hype beyond verified product behavior.

## Anti-references

No copied competitor layouts or slogans; no generic fintech security theater; no neon overload, cartoon motion, fake urgency, fake checkout success, or decorative glass-card stacks. Standard task affordances should remain familiar.

## Design Principles

- Truth before conversion: every state reflects what the system actually completed.
- One clear next action per state, especially after failures and conflicts.
- Preserve context across retries so recovery feels safe and predictable.
- Use restrained SKXNZ identity to support the task, never compete with it.
- Keep buyer-facing language free of implementation details.

## Accessibility & Inclusion

Target WCAG 2.1 AA: keyboard-operable controls, visible focus, associated labels, semantic status/error announcements, sufficient contrast, reduced-motion-safe behavior, and responsive layouts without horizontal overflow.
