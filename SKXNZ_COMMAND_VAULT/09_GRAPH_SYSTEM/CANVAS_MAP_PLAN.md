# CANVAS MAP PLAN

How to build one Obsidian **Canvas** (or Advanced Canvas) by hand.

## Steps
1. Right-click vault → New Canvas → name `SKXNZ_MASTER_CANVAS`.
2. Add center node (card): **SKXNZ COMMAND SYSTEM**.
3. Add branch nodes around it and connect with arrows:
   - **Brand** → link [[BRAND_MEMORY]], [[BRAND_COLORS]]
   - **UI/UX** → [[UI_UX_MEMORY]], [[DESIGN_RULEBOOK]]
   - **Agents** → [[AGENT_OPERATING_SYSTEM]], [[AGENT_KANBAN]]
   - **Skills** → [[SKILL_INDEX]]
   - **Animation** → [[ANIMATION_MASTER_PLAN]], [[ANIMATION_KANBAN]]
   - **Reports** → [[REPORTS_DASHBOARD]]
   - **Prompts** → [[CLAUDE_MASTER_PROMPTS]], [[CODEX_MASTER_PROMPTS]]
   - **Graph** → [[MASTER_MAP]], [[GRAPH_DASHBOARD]]
   - **Product Work Later** → [[NEXT_ACTIONS]]
4. To embed a note as a node: drag the .md file onto the canvas.
5. Save. Use as visual home.

## Tip
Keep it clean — one center, 9 branches. Don't overcrowd.
