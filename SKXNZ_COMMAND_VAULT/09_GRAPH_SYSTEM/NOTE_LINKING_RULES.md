# NOTE LINKING RULES

- Use `[[NOTE_NAME]]` (filename without `.md`), not full paths, where names are unique.
- Add a **Related:** line at the bottom of each note with 2–3 links.
- New concept → make a note + link it; don't inline-dump into an unrelated note.
- Prefer linking over copying (keeps one source of truth).
- Every note gets at least one tag in frontmatter.
- Broken/red links → create the note or fix the name.
