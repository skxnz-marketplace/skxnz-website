# GRAPH RULES

How the Obsidian graph stays useful.

- **Every important file links to 2–3 others** via `[[wikilinks]]`.
- Link to the canonical note instead of repeating content.
- Hub notes: [[MASTER_INDEX]], [[MASTER_MAP]] connect everything.
- Fix broken links when found.
- Use tags (below) so the graph clusters by theme.
