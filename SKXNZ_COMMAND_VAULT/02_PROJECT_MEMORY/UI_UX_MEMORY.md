# UI/UX MEMORY

Standing UI/UX decisions. Follow unless owner changes them.

- **Compact premium layout** — dense, tight, editorial.
- **Solid dark maroon header** (`--skxnz-maroon` #3a0818). **No glassy header** — no blur/transparency.
- **White / off-white clean background** where content needs clarity.
- **No cheap gradients.** Flat premium surfaces; subtle only if luxury.
- **No oversized text** — smaller, sharper type scale.
- **Product grid dense + seamless** — tight gutters, aligned, no clutter.
- **Brand toolbar uses logos**, not plain text.
- **Homepage must not look empty** — fill dead zones.
- **No cartoonish design.** No childish pink/blue direction.
- Fully responsive, mobile → desktop.
