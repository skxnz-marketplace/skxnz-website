# BRAND MEMORY

## Identity
- **Name:** SKXNZ. **Company:** Vivaan Poddar Companies. **Domain:** skxnz.com.
- **Tagline:** **WEAR THE SIGNAL.**
- **Category:** AI-powered, multi-seller **futurewear** fashion marketplace.

## Direction
Ultra-premium, futuristic, Gen Z, AI-powered. Editorial fashion meets sci-fi. Sharp, confident, expensive. Never generic, never childish, never template.

## Palette
Obsidian black · midnight navy · deep maroon/wine · electric cyan · ultraviolet purple · sonic magenta · liquid silver · pearl white. Accents: glass-shine, chrome. Full values → [[BRAND_COLORS]].

## Style cues
Glass-shine highlights, chrome pulse, liquid silver detailing, deep dark surfaces with pearl-white content areas where clean layout is needed.

## Hard brand rules
- **Do NOT copy existing brands** (identity, layout, wording, logo direction).
- No fake claims. No overpromising unbuilt features.
- Never distort the SKXNZ logo.
- Keep it premium + buildable.
