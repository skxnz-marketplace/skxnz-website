# 05 — UI / UX RULEBOOK

The non-negotiable design law for SKXNZ. Every agent + Codex must follow this.

## Feel
- Premium, futuristic, sharp, fashion-first. Never generic, never cheap, never childish.
- Think editorial fashion + sci-fi, not a template store.

## Color & surface
- Base background: **white / off-white**, clean.
- Header: **solid dark maroon** (`--skxnz-maroon` #3a0818). NOT glassy, NOT transparent, NOT blurred.
- Brand palette: obsidian black, midnight navy, deep maroon/wine, electric cyan, ultraviolet purple, sonic magenta, liquid silver, pearl white.
- **No cartoonish / cheap gradients.** Flat premium surfaces preferred; subtle only if it reads luxury.
- No childish pink/blue logo direction.

## Logo
- Never distort, stretch, recolor cheaply, or crop the SKXNZ logo.

## Layout
- Product grid: **dense, premium, seamless** — tight gutters, aligned, no clutter.
- Category layout: uneven fitted boxes / mosaic sections allowed and encouraged.
- Homepage must feel **full**, not empty — no large dead zones.
- Brand toolbar: use **brand logos**, not plain text.
- Remove unnecessary buttons and repeated CTAs.

## Typography
- Text **smaller and sharper** than default. No oversized headings.
- Clear hierarchy; fashion-magazine restraint.

## Interaction
- Search: live filter as user types (match typed letters); on focus show 4–5 recommended items.
- Everything responsive (mobile → desktop).
- Category strip must not clip/overflow incorrectly.

## Integrity
- No copying existing brands' identity. No fake claims. Don't show unbuilt features as live.

## Quick checklist before shipping any UI change
- [ ] White/off-white base kept?
- [ ] Header solid maroon (no glass)?
- [ ] Text compact & sharp?
- [ ] Grid dense & aligned?
- [ ] No cheap gradient added?
- [ ] Responsive at mobile width?
- [ ] No unnecessary buttons?
