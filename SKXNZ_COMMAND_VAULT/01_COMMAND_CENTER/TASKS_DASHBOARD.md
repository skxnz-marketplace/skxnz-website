# ✅ TASKS DASHBOARD

Powered by **Tasks** plugin. Write tasks anywhere as `- [ ] text` with optional tags/dates; they show here.

## How to write a task
```
- [ ] Test one Claude agent #agent 📅 2026-07-02
- [ ] Loading screen motion #animation
- [ ] Fill daily report #daily-report
- [ ] Blocked: apply catalog DB #blocked
```
Dates: `📅 YYYY-MM-DD` due · `⏫`/`🔼`/`🔽` priority · `#blocked` for blockers.
