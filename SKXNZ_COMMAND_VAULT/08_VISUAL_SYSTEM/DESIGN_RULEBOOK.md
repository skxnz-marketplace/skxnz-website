# DESIGN RULEBOOK

Single design law for SKXNZ. All agents + Codex follow this.

## Feel
Premium, futuristic, sharp, fashion-first. Editorial + sci-fi. Never generic/childish/template.

## Surface & color
- Base: white / off-white, clean, where content clarity needed.
- Header: **solid dark maroon** (`--skxnz-maroon` #3a0818). No glass/blur/transparency.
- Dark surfaces: obsidian (#100006), maroon-deep (#1a030b), wine (#4b1022).
- Accents: electric cyan, ultraviolet purple, sonic magenta, liquid silver, glass-shine, chrome.
- **No cheap gradients.** Flat premium; subtle only if luxury.

## Layout
- Dense, seamless product grid. Tight gutters, aligned.
- Homepage full, not empty. Category mosaic/uneven boxes allowed.
- Brand toolbar uses logos.
- Remove unnecessary buttons/CTAs.

## Type
Small + sharp. Clear hierarchy. No oversized headings. See [[TYPOGRAPHY_RULES]].

## Motion
Per [[ANIMATION_MASTER_PLAN]]; banned patterns in [[MOTION_DO_NOT_DO]].

## Integrity
No brand copying. No fake claims. Logo never distorted. Responsive always.
