# COMPONENT RULES

## Header / nav
Solid dark maroon. No glass. Compact height. Logo undistorted. Minimal items.

## Product card
Dense, compact spacing, small sharp text. Image-forward. Hover per [[PRODUCT_CARD_MOTION]]. No heavy borders/shadows.

## Product grid
Tight gutters, aligned, seamless. Fill space; no huge gaps.

## Brand toolbar
Brand **logos**, not text. Even spacing. Subtle hover shine.

## Buttons
Few, purposeful. Premium flat style. Remove redundant CTAs.

## Search
On focus: 4–5 recommended. Typing: live letter filter.

## Category strip
No clipping/overflow. Mosaic/uneven boxes allowed.

## Cards/sections generally
No cartoonish styling, no cheap gradient fills, consistent radius + spacing scale.
