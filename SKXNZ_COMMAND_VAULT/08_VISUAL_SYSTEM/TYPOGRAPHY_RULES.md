# TYPOGRAPHY RULES

## Verified fonts (loaded in `app/globals.css`)
- **Source Sans 3** — body / UI text.
- **Bodoni Moda SC** — display / editorial headings (fashion feel).
- **Merriweather Sans** — secondary / supporting.

## Rules
- Text **small + sharp**. No oversized headings.
- Strong hierarchy: display (Bodoni) for statement headings, Source Sans for body.
- Tight, readable line-height; generous letter-spacing only on small caps/labels.
- Limit font sizes — a controlled scale, not many random sizes.
- High contrast on dark surfaces (pearl white on obsidian/maroon).
- Responsive scale; never let mobile text balloon.

## Avoid
Oversized hero text, too many weights, decorative fonts beyond the three loaded, low-contrast gray-on-white.
