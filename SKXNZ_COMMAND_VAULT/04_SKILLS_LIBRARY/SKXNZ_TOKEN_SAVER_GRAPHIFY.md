# SKILL — SKXNZ Token Saver / Graphify

**When:** notes get long; context/token cost rising; connecting the vault graph.
**Inputs:** target notes + [[GRAPH_RULES]] + [[TAG_SYSTEM]].
**Process:**
1. Compress prose to fragments (keep all technical substance, code, URLs).
2. Replace repetition with wikilinks to the canonical note.
3. Ensure each important note links to 2–3 others.
4. Apply correct tags.
5. Move dead content to [[ARCHIVE_RULES]] flow.
**Output:** shorter note + link/tag additions.
**Quality checklist:** meaning intact? links added? tags correct? shorter?
**Failure modes:** deleting real info, broken links, over-compressing until unclear.
**SKXNZ rules:** never lose technical facts to save tokens.
