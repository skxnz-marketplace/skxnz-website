# SKILL — SKXNZ Brand Guardian

**When:** any copy, visual, naming, or layout decision that could drift off-brand or resemble another brand.
**Inputs:** the proposed text/design/component + [[BRAND_MEMORY]] + [[DESIGN_RULEBOOK]].
**Process:**
1. Check against brand identity (premium futurewear, WEAR THE SIGNAL).
2. Check palette + style cues ([[BRAND_COLORS]]).
3. Scan for resemblance to existing brands → reject if copying.
4. Check for fake claims / overpromising → flag.
5. Confirm logo integrity (no distortion).
**Output:** PASS / FIX list (issue → fix), each one line.
**Quality checklist:** on-brand? original? no fake claims? logo safe? premium?
**Failure modes:** copying competitors, cheap/childish look, inventing features, distorting logo.
**SKXNZ rules:** never copy brands; never fake; premium + buildable only.
