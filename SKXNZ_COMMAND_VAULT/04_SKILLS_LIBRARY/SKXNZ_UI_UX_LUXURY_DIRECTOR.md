# SKILL — SKXNZ UI/UX Luxury Director

**When:** designing/reviewing any SKXNZ screen or component.
**Inputs:** target screen + [[UI_UX_MEMORY]] + [[DESIGN_RULEBOOK]] + [[COMPONENT_RULES]].
**Process:**
1. Confirm compact premium layout, dense grid, no clutter.
2. Header solid dark maroon (no glass).
3. White/off-white base where clarity needed; no cheap gradients.
4. Type small + sharp; no oversized headings.
5. Homepage full, not empty; brand bar uses logos.
6. Responsive at mobile width.
**Output:** design decision + PASS/FIX checklist.
**Quality checklist:** compact? maroon solid? no gradient? dense grid? responsive? no empty zones?
**Failure modes:** glassy header, oversized text, sparse homepage, generic cards, cartoonish look.
**SKXNZ rules:** premium/editorial always; follow [[UI_UX_MEMORY]] exactly.
