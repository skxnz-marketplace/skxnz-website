# SKILL — SKXNZ Obsidian Reporter

**When:** end of any work block; when status/bugs change.
**Inputs:** what was done, files touched, [[07_REPORTS/DAILY_REPORT_TEMPLATE]].
**Process:**
1. Fill correct report template (daily/claude/codex/bug/handoff).
2. Update [[CURRENT_STATUS]] + [[NEXT_ACTIONS]].
3. Log decisions in [[DECISION_LOG]].
4. Add wikilinks + tags (see [[GRAPH_RULES]]).
5. Verify no false "done" claims.
**Output:** completed report + updated status files.
**Quality checklist:** accurate? linked? tagged? no fake claims? next steps clear?
**Failure modes:** stale status, missing links, inflated progress.
**SKXNZ rules:** vault must always reflect real code state.
