# SKILL — SKXNZ Animation Director

**When:** planning/reviewing any motion.
**Inputs:** target element + [[ANIMATION_MASTER_PLAN]] + [[MOTION_DO_NOT_DO]].
**Process:**
1. Match SKXNZ motion language: premium, smooth, fast, glass-shine, chrome pulse.
2. Respect priority order (loading → hero → menu → cards → brand bar → search → transitions).
3. Keep durations short (fast, not laggy); ease premium.
4. Check against [[MOTION_DO_NOT_DO]].
5. Respect reduced-motion accessibility.
**Output:** motion spec (element, trigger, duration, easing, effect) + PASS/FIX.
**Quality checklist:** fast? smooth? premium? not distracting? reduced-motion safe?
**Failure modes:** cartoon bounce, over-animation, neon overload, laggy transitions, distorted logo.
**SKXNZ rules:** never cheap/childish; motion serves luxury, not spectacle.
