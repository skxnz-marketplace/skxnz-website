# HERO CAROUSEL MOTION

Priority #2.

- **Slide transition:** cross-fade + subtle horizontal drift (not hard slide), 300ms ease-out.
- **Auto-advance:** slow (6–8s), pause on hover/focus.
- **Text:** headline fades + rises 12px, 240ms; CTA appears just after.
- **Glass-shine:** one subtle sweep on active slide image.
- **Controls:** minimal dots/arrows; hover chrome pulse.
- **Reduced motion:** static first slide, manual advance only.

Do NOT: fast flashing, aggressive zoom, bouncing arrows, neon overlays.
