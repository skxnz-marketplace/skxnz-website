# LOADING SCREEN MOTION

Priority #1. First impression of SKXNZ.

- **Concept:** obsidian background, SKXNZ logo center, single glass-shine sweep + soft chrome pulse.
- **Duration:** minimal — show only while assets load; fade out ≤300ms once ready. Never artificially delay.
- **Effect:** one light sweep across logo (left→right, ~600ms), gentle pulse glow.
- **Logo:** never distorted, never spun, never stretched.
- **Exit:** fade to homepage; hero begins after.
- **Reduced motion:** static logo + instant fade.

Do NOT: bounce, spin, progress-bar gimmicks, neon flashing.
