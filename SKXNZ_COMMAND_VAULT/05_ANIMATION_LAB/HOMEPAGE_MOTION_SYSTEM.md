# HOMEPAGE MOTION SYSTEM

How motion behaves across the homepage.

- **Section reveal:** fade + slight rise (16px) on scroll into view, 240ms, once. No repeat on re-scroll.
- **Hero:** see [[HERO_CAROUSEL_MOTION]].
- **Brand bar:** logos fade in staggered (40ms step), subtle glass-shine on hover.
- **Product rows:** cards enter with soft stagger; hover per [[PRODUCT_CARD_MOTION]].
- **Trust bar / banners:** static or minimal; no looping animation.
- **No parallax overload, no background particles.**

Stagger keeps homepage feeling full + alive without clutter (supports "not empty" rule in [[UI_UX_MEMORY]]).
